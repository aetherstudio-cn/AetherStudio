模块按职责划分为三个子目录：
- `tests/`：以 `run_tests.ps1` 为统一入口，通过 `-Suite` 参数分发到 unit（`cargo test --workspace`）、gui（遍历 `cases/*.tests.ps1`）、ai（`ai/selfcheck.ps1`）、coverage（`tools/coverage.ps1`）四类用例；GUI 用例依赖 `framework/AetherTest.psm1` 核心模块（应用生命周期、窗口/输入模拟、截图、日志观测、hit regions 读取、JSON 报告）和可选的 `framework/AetherAi.psm1` 高级层（动作脚本 DSL、像素断言、UI 状态快照、失败诊断包打包）。用例通过 `Start-TestCase` / `Invoke-TestStep` / `Complete-TestCase` 三段式协议编写，输出 JSON 报告至 `reports/`、截图至 `screenshots/<case>/`。
- `scripts/`：`build-release.ps1` 封装 cargo 构建并输出目标路径；`migrate_editor_state_v*.ps1` 系列按版本递增对 Rust 源码进行字段路径批量重命名（如 `st.field` → `domain.field`），由 `split_impl_editor_state.ps1` 触发执行。
- `deliverables/software-company/`：UX 架构文档与 Mermaid 类图/时序图，作为交付物归档。
依赖方向单向：`AetherAi.psm1` → `AetherTest.psm1` → Windows API（`user32.dll`/`kernel32.dll` via inline C#），用例仅依赖框架，不反向依赖。
