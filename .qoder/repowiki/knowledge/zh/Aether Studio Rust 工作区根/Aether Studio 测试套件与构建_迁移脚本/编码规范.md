- GUI 用例遵循三段式协议：导入 `AetherTest.psm1`（及可选 `AetherAi.psm1`）→ `Start-TestCase` → 若干 `Invoke-TestStep` → `exit (Complete-TestCase)`，每个步骤异常被捕获并计入报告但不中断后续步骤。
- 输入模拟优先使用 `Send-Aether*Msg` 系列（PostMessage 注入 WM_* 消息），避免受前台窗口遮挡或焦点影响；真实鼠标点击仅在必要时使用 `Invoke-AetherClick`。
- 坐标一律采用窗口内物理像素 = 名义布局常量 × Scale²（Scale=DPI/96），通过 `Get-AetherLayoutConstants` 获取布局常量，`Get-AetherWindow` 返回 `Scale`/`Scale2` 供换算。
- 通过 `tests/gui_hit_regions.jsonl` 中的 hit region 进行语义定位（如 `titlebar:settings`、`settings_tab:general`），用例不手写绝对坐标，改用 `Wait-AetherHitRegion` / `Invoke-AetherSmartClick` 自动查找并点击。
- 日志观测使用 `Get-AetherLogMark` + `Get-AetherLogSince` 或 `Wait-AetherLogEvent` 只观察标记之后新增的行，避免匹配历史会话污染；异步等待统一带超时与轮询间隔。
- 编辑器状态迁移脚本按版本号递增（v1..v8），每个脚本维护独立的 `$fieldMap` 映射表，使用正则替换 `st\n.field` 跨行模式为目标域前缀，并在末尾汇总统计修改文件数与替换次数。
