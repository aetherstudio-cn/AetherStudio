本模块为整个 Rust + Win32 编辑器项目的顶层组织：
- `Cargo.toml` 声明 workspace resolver=2，聚合 15 个 crate（aether-core / render / win32 / lsp / dap / plugin / remote / ai / shared / cli / editor / ai-panel / db / terminal / ui / render-win），统一版本、edition 与 release profile（fat LTO、单 codegen unit、strip、panic=abort）。
- `rust-toolchain.toml` 锁定 stable toolchain 并启用 rustfmt/clippy 组件，目标平台固定为 x86_64-pc-windows-msvc。
- `.cargo/config.toml` 提供 Cargo 级构建配置。
- `installer/` 包含 NSIS 脚本 `aether-setup.nsi` 及打包好的 `aether-setup.exe`，用于生成 Windows 安装包。
- `scripts/` 提供 PowerShell 构建与迁移脚本（build-release.ps1、migrate_editor_state_v*.ps1、split_impl_editor_state.ps1 等），承担版本升级与发布流程。
- `tests/` 是 GUI 自动化测试套件：PowerShell 用例（cases/*.tests.ps1）、Pester 风格框架（framework/AetherTest.psm1、AetherAi.psm1）、截图对比目录（screenshots/）、报告与覆盖率收集（tools/coverage.ps1）。
- `.github/workflows/`、`.github/PULL_REQUEST_TEMPLATE.md`、`.trae/`、`deliverables/software-company/` 分别承载 CI、PR 模板、AI 辅助规范与交付文档。
依赖方向由上层 crate 通过 workspace 成员引用，根仅做编排与基础设施，不引入业务逻辑。
