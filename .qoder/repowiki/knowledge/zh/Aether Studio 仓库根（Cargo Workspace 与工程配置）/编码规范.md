- Workspace 内所有 crate 通过 `Cargo.toml` 的 `[workspace].members` 集中注册，统一版本号与 release profile，避免各 crate 各自定义构建参数。
- 测试用例以 PowerShell 脚本形式组织在 `tests/cases/`，每个功能一个独立 `.tests.ps1` 文件，配合 `tests/framework/AetherTest.psm1` 提供的 Pester 风格断言与 UI 操作封装。
- GUI 测试采用截图对比策略：预期截图存放于 `tests/screenshots/<case>/`，运行时生成新截图并与基线比对，失败产物输出到 `tests/reports/`。
- 编辑器状态迁移通过 `scripts/migrate_editor_state_vN.ps1` 按版本号递增演进，每次结构变更新增 vN 脚本而非修改旧脚本，保证向后兼容。
- 发布构建统一通过 `scripts/build-release.ps1` 调用 cargo 并应用 fat LTO、单 codegen unit、strip 等优化选项，确保可分发二进制一致性。
